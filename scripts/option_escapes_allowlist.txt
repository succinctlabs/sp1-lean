# Allowlist for elaboration-budget escape hatches — enforced by scripts/check_option_escapes.sh.
#
# Format:  <option>  <path>  <value>  <count>   # justification
#
# The key is (option, path, value) and the count must match EXACTLY. Any site not listed here fails
# the build; so does raising a listed value, or adding a second site at the same value to a listed
# file. This is a PROHIBITION with named exceptions, not a budget.
#
# Every entry below carries a measured ladder. The 2026-07/08 campaign took hand-written
# `maxHeartbeats` from 638 to ZERO and hand-written `maxRecDepth` from 44 to 3 by diagnosing and
# fixing causes; nothing here was kept because it was merely unexamined. Before adding an entry, read
# docs/agents/perf-findings.md §12 — extract over OPAQUE arguments, and check what the extraction can
# still see. Five of the six escape hatches this campaign inherited fell to that one rule.
#
# For calibration: upstream Clean has ZERO `maxHeartbeats` in 44,603 lines and 4 `maxRecDepth` sites,
# all in constant tables, capped at 2048, none in a proof.
#
# ---- maxHeartbeats: 3 sites, all on GENERATED definitions ----------------------------------------
# Hand-written Lean in this repo carries none. All three below are emitted by update_extracted.py and
# are reproduced by a regeneration; fixes go in the generator, never by editing the file.

# barely over the default; set ~2x because codegen cost tracks toolchain changes less predictably than
# elaboration. Removable only via `noncomputable`, which cascades into hand-written Faithful/ files;
